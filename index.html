Featured Lesson

Flexbox: one-dimensional layout

Flexbox lays items out in one direction at a time, in a row or in a column. Set display: flex on the container and its direct children become flex items. 

.toolbar {
    display: flex;
    gap: 1rem;
    justify-content: space-between;
}

Grid: layout in rows and columns

Grid places items in rows and columns at the same time. The repeat() and minmax() functions with auto-fit make a card grid that fits any screen width. 

.card-grid {
    display: grid;
    gap: 1rem;
    grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
}

Media queries: changing layout by screen width

Mobile-first CSS writes the small-screen styles first. Then a media query with min-width adds changes for wider screens. 

.layout {
    display: grid;
    grid-template-columns: 1fr;
}

@media (min-width: 768px) {
    .layout {
        grid-template-columns: 1fr 1fr;
    }
}
